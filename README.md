# El Pollo Loco

A 2D jump-and-run game built with HTML, CSS and JavaScript.

## Description

El Pollo Loco is a 2D browser game where the player controls Pepe.
The goal is to collect coins, defeat enemies and reach the end of the level.

## Features

- Move and jump with the character
- Throw bottles at enemies
- Collect coins
- Fight different chicken enemies
- Collect bottles
- Sound effects and background music
- Responsive game layout

## Controls

| Key | Action |
|---|---|
| ← / → | Move left / right |
| ↑ | Jump |
| Space | Throw bottle |

## Technologies

- HTML5
- CSS3
- JavaScript
- HTML Canvas

## How to Play

Open the game in your browser and start playing.
